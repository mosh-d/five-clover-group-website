# Audit, November 2026: the group website and the PMS

Round 1 of the AI coding kit's audit, done on 2026-11-27 when the kit was adopted. **Nothing has been changed yet.** The backend's findings (AUD-nn) are in `../five-clover-nestjs-backend/docs/audit-2026-11.md`; this file's are AUD-Wnn.

**How it was checked:** reading `next.config.mjs`, `public/_headers`, the PMS session and live-update code, `npm audit --omit=dev`, and the built `out/` folder. **Not checked:** the live headers on fivecloverhotels.com (read-only requests, next round), Lighthouse/axe runs on the public pages, whether the Google Tag Manager id is set in production.

## Findings by severity

| ID | Severity | Finding | Evidence | Fix (cost) |
|---|---|---|---|---|
| AUD-W01 | **Medium** | **No security headers of our own:** no Content-Security-Policy, `X-Frame-Options`/`frame-ancestors`, `Referrer-Policy` or `Permissions-Policy`; HSTS depends on Cloudflare's setting. With the PMS session in localStorage (backend AUD-05), a CSP is the main defence against a script stealing it. | `public/_headers` has cache rules only. | Headers in `public/_headers`; a CSP with hashes for Next's inline scripts (no `unsafe-inline`), allowing the API host, Google Tag Manager and fonts. Test with the PMS and the site. (M) |
| AUD-W02 | **Medium** | **Dependency advisories:** `next` (critical), `postcss`, `sharp`, `nanoid`, `source-map-js` (high), `baseline-browser-mapping` (moderate). Most of `next`'s are in its server, which a static export doesn't run, so the real exposure is low; still, upgrade. | `npm audit --omit=dev`, 2026-11-27. | Upgrade Next.js and the rest within the major version; build and run the PMS tests. (S) |
| AUD-W03 | **Medium** | **Polling remains, against the "no polling" rule (D-09):** Overview reloads every 60 s; the OTA-payments and cash-up counts every 60 s; the update check every 5 min; a fallback timer while the live connection is down. | `app/pms/overview/page.jsx:45,109`; `components/pms/live/PmsLive.jsx:41,104,131,305`; `components/pms/UpdateButton.jsx:11,24`. | Push these over the live connection like the other counts; keep the outage fallback and the update check (cheap, static file) if the owner agrees. (M) |
| AUD-W04 | **Medium** | **Analytics without consent:** Google Tag Manager / Analytics set cookies with no consent banner. Flag for a lawyer under the NDPA. | `components/seo/GoogleAnalytics.jsx`. | Cookieless analytics (Cloudflare Web Analytics, free), or a banner that really blocks GTM until accepted. Owner decides. (S) |
| AUD-W05 | **Medium** | **No automatic check on push** (lint, tests, build). | No `.github/workflows/`. | One workflow running `npm run lint`, `npm test`, `npm run build`; branch protection on `main`. (S) |
| AUD-W06 | **Low** | A stray source map is in the build output (`out/_next/static/chunks/*.js.map`, not referenced by any script). | `find out -name "*.map"`. | Don't copy it to the export, or confirm it's harmless. (S) |
| AUD-W07 | **Low** | **Runtime not pinned** (no `.nvmrc`/`engines`). | `package.json`. | Pin Node LTS. (S) |
| AUD-W08 | **Low** | `/pms` isn't in `robots.txt`; its pages carry `noindex`, which is enough. Recorded so it isn't added to robots (which would list it). | `app/robots.js`, `app/pms/layout.jsx:11`. | None. (—) |
